# Firstmate roles

The portable primary uses Codex with GPT-6.1 Sol and high reasoning where supported.
The Firstmate checkout is `~/karan-agent-workspace` by default.
`FM_HOME` can select another absolute home at install and launch time.

Firstmate owns the task brief, project registration, worker dispatch, durable supervision, and guarded merge.
A worker owns one isolated task and reports only to its supervising Firstmate.
Merge and deployment authority remain defined by the registered task and project contracts.

The installer selects the supported Herdr backend and Codex dispatch config.
It does not migrate private captain preferences or task state.
The [workflow guide](HOW-WE-WORK.md) records startup and delivery procedures.
The clone's tracked `AGENTS.md`, `docs/configuration.md`, and `bin/fm-spawn.sh` remain authoritative.
